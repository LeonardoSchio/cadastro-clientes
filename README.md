# Sistema de Gestão de Clientes

## 📋 Sobre o projeto

Projeto desenvolvido em Java com o objetivo de criar um sistema para
cadastro e gerenciamento de clientes.

O projeto está sendo desenvolvido de forma incremental, acompanhando meu
aprendizado em Java e aplicando na prática conceitos de Programação
Orientada a Objetos, Collections, Generics, Exceptions e Stream API.

Atualmente, os dados são armazenados em memória utilizando Collections do Java.

## 🚀 Funcionalidades atuais

- Cadastro de clientes
- Listagem de clientes
- Busca de clientes
- Filtragem de clientes
- Listagem de e-mails
- Cálculo do valor total de compras
- Identificação de clientes com maior valor de compras

## 🛠️ Tecnologias utilizadas

- Java

- IntelliJ IDEA
- Git

## 📚 Conceitos praticados

- Programação Orientada a Objetos (POO)
